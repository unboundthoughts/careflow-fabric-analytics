# CareFlow Fabric Analytics

CareFlow Fabric Analytics is a fictional healthcare analytics project built using Microsoft Fabric.

The purpose of this project is to demonstrate an end-to-end analytics solution using:

- Source CSV files
- Microsoft Fabric Data Factory
- Lakehouse
- Warehouse
- Semantic Model
- Power BI
- GitHub source control
- Deployment pipelines

## Current Project Stage

The project currently contains the source CSV files that will be used as the starting point for the Fabric build.

## Source Data

The source data is stored in the `01_Source_Data` folder and contains:

- Service.csv
- Location.csv
- Indicator.csv
- CareActivity.csv
